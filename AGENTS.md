# Правила работы с репозиторием

## Назначение файлов

- `index.js` — единственный редактируемый исходный файл Cloud Function.
- `index.compact.js` — автоматически сгенерированная компактная версия `index.js`.
- `scripts/build-compact.js` — генератор компактной версии.
- `scripts/check-compact.js` — проверка результата.

## Запрет ручного редактирования

Никогда не редактировать `index.compact.js` вручную.

Любые функциональные изменения необходимо вносить только в `index.js`, после чего выполнять:

```bash
npm run compact:verify
