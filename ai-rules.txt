ПРАВИЛА ДЛЯ НЕЙРОСЕТЕЙ ПО РЕПОЗИТОРИЮ vi3-signaling-compact-test

ОБЩИЕ ПРАВИЛА:

- Язык ответов: русский.
- Проект редактируется через web-интерфейс github.com.
- Всегда указывать точные пути изменяемых файлов.
- Формат инструкций: ФАЙЛ -> НАЙТИ -> ЗАМЕНИТЬ НА.
- Любой код оформлять в блоках кода с указанием языка.
- Не изменять функциональную логику без прямого запроса пользователя.

НАЗНАЧЕНИЕ РЕПОЗИТОРИЯ:

- index.js является исходником Yandex Cloud Function vi3-signaling.
- index.compact.js является автоматически генерируемой читаемой компактной версией.
- index.compact.js нельзя редактировать вручную.
- Функциональные изменения вносятся только в index.js.
- После изменения index.js необходимо заново создать index.compact.js.

ФОРМАТ INDEX.COMPACT.JS:

- Это не минифицированный файл.
- Это читаемый JavaScript с плотным горизонтальным форматированием.
- Функции и управляющие блоки должны сохранять нормальную многострочную структуру.
- Короткие массивы должны размещаться в одной строке.
- Короткие объекты должны размещаться в одной строке.
- Аргументы функций по возможности должны размещаться в одной строке.
- Допускаются строки длиной до 240 символов.
- Комментарии должны сохраняться.
- SQL и содержимое шаблонных строк нельзя изменять.
- Числовые литералы нельзя намеренно преобразовывать в экспоненциальную форму.
- Нельзя использовать Terser, UglifyJS или другой минификатор.
- Для генерации используется Prettier.
- Нельзя включать compress или mangle.

АРХИТЕКТУРНЫЕ ОГРАНИЧЕНИЯ:

- Формат модулей: CommonJS.
- Главный исходный файл: index.js.
- Экспорт Cloud Function: exports.handler.
- Нельзя преобразовывать CommonJS в ESM.
- Нельзя переименовывать actions.
- Нельзя менять имена переменных окружения.
- Нельзя менять строки ошибок.
- Нельзя менять SQL-запросы.
- Нельзя менять порядок операций.
- Нельзя удалять проверки безопасности.

ОБЯЗАТЕЛЬНАЯ ПРОВЕРКА:

- node --check index.js
- node scripts/build-compact.js
- node --check index.compact.js
- node scripts/check-compact.js

КОНТЕКСТ РЕПОЗИТОРИЯ:

- index.js не включается в repository-full.txt.
- index.compact.js не включается в repository-full.txt.
- .git, .meta и node_modules не включаются.
