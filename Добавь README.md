# vi3-signaling compact test

Тестовый репозиторий для автоматического создания компактной версии Yandex Cloud Function.

## Файлы

- `index.js` — исходная версия;
- `index.compact.js` — автоматически созданная компактная версия;
- `scripts/build-compact.js` — генератор;
- `scripts/check-compact.js` — проверка.
